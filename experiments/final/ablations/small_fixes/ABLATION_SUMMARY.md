# First Iteration Ablation Study - Overview

## What We're Testing

This ablation study systematically compares different training approaches and hyperparameters to find the optimal method for training proof optimization models. The study has three main components that build on each other.

**Phase 1: Basic Training Methods (SFT vs wSFT).** We first compare standard Supervised Fine-Tuning (SFT) against weighted SFT (wSFT). SFT trains on all successful proof improvements equally, while wSFT assigns weights based on improvement quality and variance across multiple samples. For SFT, we ablate learning rates (1e-06, 5e-06, 1e-05, 2e-05) to find optimal convergence. For wSFT, we ablate both learning rates AND data filtering parameters (variance thresholds of 0.5, 0.8, 1.0), where lower thresholds keep only high-confidence improvements. This phase identifies whether example weighting helps and what hyperparameters work best for each approach.

**Phase 2: Preference Learning Methods (IRPO vs DPO).** Using the best model from Phase 1 as initialization, we test preference-based training methods that learn from comparisons between good and bad proof attempts. We ablate IRPO (Iterative Rejection Policy Optimization) across multiple dimensions: (1) winner-to-loser ratios (W1/L1, W2/L1, W2/L2, W4/L4) to test how many positive vs negative examples work best, (2) minimum quality gaps (0, 1, 2 tactic difference) to test whether we need strong preference signals or if weak preferences help, and (3) learning rates for each configuration. We compare this against DPO (Direct Preference Optimization) with similar ablations. This phase determines whether preference learning improves over pure supervised learning and which preference algorithm and configuration works best.

**Phase 3: Pipeline Selection.** Finally, we evaluate all trained models on held-out test data and select the best end-to-end training pipeline. The key research questions are: (1) Does weighted training (wSFT) improve over standard SFT? (2) Does preference learning (IRPO/DPO) improve over supervised learning alone? (3) What hyperparameters and data filtering strategies work best at each stage? (4) Is there a quality-quantity tradeoff in training data (high variance threshold = more data but noisier vs low threshold = less data but higher quality)? The final output is an optimal training recipe for the next iteration of expert iteration.
